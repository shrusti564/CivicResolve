# Public Bengaluru data sources

- OpenCity Bengaluru dataset catalogue: https://data.opencity.in/
- BBMP Grievances Data: search catalogue by exact title “BBMP Grievances Data”.
- BBMP Fix My Street Data: search catalogue by exact title “BBMP Fix My Street Data”.
- BBMP Ward Information: search catalogue by exact title “BBMP Ward Information”.
- Bengaluru Streetlights: search catalogue by exact title “Bengaluru Streetlights”.
- BBMP Solid Waste Management Data: search catalogue by exact title.
- Flooding Locations in Bengaluru Urban: search catalogue by exact title.
- BBMP Work Orders: search catalogue by title.
- BDA Jurisdiction and Boundary: search catalogue by exact title.
- Greater Bengaluru Wards 2025 (369 wards): https://bharatlas.com/layers (download GeoJSON; listed CC0-1.0).

The downloader uses OpenCity's CKAN API to discover the current resource URLs instead of hard-coding potentially expiring CSV download links.
