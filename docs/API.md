# API reference

Base URL: `http://127.0.0.1:8000`. FastAPI also exposes interactive docs at `/docs`.

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Service status and whether Gemini is configured. |
| GET | `/api/geo/ward?latitude=12.97&longitude=77.59` | Point-in-polygon ward lookup; reports a no-match when boundaries are unavailable/outside. |
| GET | `/api/geo/wards` | GBA boundary GeoJSON; 404 if not downloaded. |
| POST | `/api/complaints` | Multipart form: title, description, category; optional priority, latitude, longitude, address, location_source, image. Returns the stored complaint and reference. |
| GET | `/api/complaints` | List live local submissions (includes clearly prefixed synthetic demo seed rows on a fresh database). |
| PATCH | `/api/complaints/{id}/status` | JSON `{"status":"In Progress"}`; allowed: Submitted, Under Review, In Progress, Resolved, Rejected. Returns updated record; 400 invalid status, 404 missing record. |
| GET | `/api/dashboard/historical` | Historical 2019–2022 analytics. |
| GET | `/api/dashboard/historical/geo` | Historical GPS points, separate from live submissions. |
| GET | `/api/datasets` | Local file inventory and dataset manifest status. |
| POST | `/api/rag/ingest` | Re-index supported local PDF/TXT/Markdown files under `data/knowledge/`. |
| POST | `/api/ask` | JSON `{"question":"..."}`; returns answer, retrieved source chunks, and grounded flag. |

Errors use FastAPI JSON `detail` responses when generated by the application. Uploaded images must have JPG/JPEG/PNG/WEBP extension and matching file signature, and may not exceed 5 MB. Multipart requests must be sent as `FormData`; clients must not set the multipart `Content-Type` header themselves.

There is no authentication or authorization on this prototype. Do not expose admin, status-update, or ingestion endpoints to a public network without adding access controls.
